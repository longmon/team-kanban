# 设计规范（方向 A：长春花工作台）

改 UI 以本文为依据。token 唯一定义处是 `web/src/theme.css`（`:root` 亮色、`.dark` 暗色），`web/src/index.css` 的 `@theme inline` 把它们注册成 Tailwind 工具类（`bg-primary`、`bg-primary-soft`、`bg-tone-f`、`text-tone-ink`、`shadow-pop`、`ease-rise` 等）。组件是 shadcn/ui（`web/src/components/ui`，`web/components.json` 已按官方方式初始化，可用 `npx shadcn@latest add` 管理；新增组件须把默认样式映射到本文 token），OpenUI 渲染组件 kanbanLibrary 在 `web/src/openui-lib`，两者共用同一套 token。

方向：熟悉的三栏工作台，白净安静；唯一的大胆是右栏那块长春花蓝的实色「等我处理」面板，眼睛第一落点永远是要你做的事。雾白画布 + 白卡 + 夜墨字 + 长春花蓝主色；珊瑚表示截止与提醒，薄荷表示已完成、实时与锁定。圆角卡片 14、面板 18、按钮与小块 10、胶囊 999。卡片只用 1px 描边、无阴影，只有浮层（菜单、对话框、命令栏、toast）一档柔影 `0 8px 24px rgb(22 26 51 / .10)`。不用渐变背景、毛玻璃、手写体；不用全大写小标签、「A · B · C」中点拼接、按钮文字后加 →。

信息架构：登录后左侧固定导航（品牌、组织切换、工作台 / 等我处理（珊瑚数字角标）/ 我发布的、项目列表带页面数、底部当前用户与设置菜单），`lg`（1024）以下收成顶部条 + 抽屉。首页 `/` 是工作台（`?view=todo|mine` 对应导航「等我处理 / 我发布的」），项目页 `/o/:org/p/:project` 是同一套工作台只看该项目（成员与设置在右上角 Tab，`?tab=`）。页面详情：面包屑 + 搜索框、题头、锁定提示条、主区 + 右栏（实时结果、版本、还没参与的人、页面信息、分享链接 / 复制链接 / 管理）。

### 页面类型色

每种类型一组变量：强调色 `--t-x`（图标、缩略图描边）、浅底 `--t-x-f`（图标方块、缩略图填充；`-l` 同值，保留变量名）、文字色 `--t-x-ink`。元素加 `data-tone="vote|form|report|flow|arch|book"` 后用 `bg-tone-f` / `bg-tone` / `text-tone` / `text-tone-ink`。

## 2. 字体

- 拉丁字母与数字：**Onest**（自带等宽数字 tnum，OFL；可变字重，自托管 `@fontsource-variable/onest`，由 `web/src/main.tsx` 引入，按 unicode-range 只拉用到的子集；CSP 为 `font-src 'self' data:`，不能用 Google Fonts CDN）。

## 3. 圆角

`--radius: 10px`：`rounded-lg` = 10px（按钮、输入框、小块）。专用：卡片 `rounded-[14px]`、右栏卡片 16px、等我处理面板 18px、待办卡 13px、分段控件 11px（选中块 8px）、类型图标方块 10px（详情 14px）、徽标与头像 `rounded-full`。

## 4. 阴影

零阴影：层级只靠颜色深浅与尺寸。

| 工具类 | 用途 |
|---|---|
| `shadow-pop` | 唯一一档投影：下拉菜单、Select、对话框（含「管理页面」）、AlertDialog、命令栏、toast、图表 tooltip |
| `shadow-card` | 值为 1px `border` 色描边（不是投影）：`surface` 工具类 = `rounded-[20px] bg-card shadow-card`，OpenUI 卡片沿用；筛选分段的选中块 |
| `shadow-card-hover` | 值为 1px `input` 色描边 |

`shadow-primary` / `shadow-primary-press` 保留变量名，值为 `none`。

## 5. 动效

原则：静止时外观与无动效时完全一致，只在交互、数据变化或首次进入时出现；每个动效都要能回答「它告诉用户什么」；时长 150–500ms；悬停只换颜色。交互组件 Tabs / Dialog / AlertDialog / DropdownMenu / Tooltip / Accordion / Checkbox / RadioGroup / Switch 用 animate-ui（基于 motion）；格子墙、正在发生、票卡翻面等页面级动效用 motion（`motion/react`）；其余用浏览器原生能力（CSS、View Transitions、IntersectionObserver）。全部随包打进 bundle，符合 CSP `script-src 'self'`。

| 变量 | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 150ms | 颜色切换、格子淡出 |
| `--dur-base` | 200ms | 默认过渡、命令栏缩放淡入 |
| `--dur-slow` | 250ms | 路由切换淡入 |
| `--dur-flip` | 500ms | 票卡翻面、填充上涨 |
| `--ease-standard` | `cubic-bezier(.2,.8,.2,1)` | 统一缓动 |
| `--ease-rise` | `cubic-bezier(.22,1,.36,1)` | 填充上涨、格子入场与重排、进度环 |
| `--ease-pop` | `cubic-bezier(.3,1.5,.5,1)` | 只用于 ≤ 24px 的小元素弹入 |
| `--ease-spring` | `linear(…)` 过冲约 5% | 按钮松开回弹 |

| 动效 | 规范 | 实现位置 |
|---|---|---|
| **标志：投票翻面** | 提交成功、票卡第一次拿到结果时，整组票卡沿 Y 轴翻面 500ms（前 250ms 转到侧面 `rotateY 0→90°`，切换成结果态，后 250ms 从 `-90°` 转回），透视 2400px；页面加载时已是结果态则不翻 | `openui-lib/forms.tsx` `Tickets` / `useFlip` |
| **标志：票卡填充上涨** | 结果态票卡底部（竖排大行为左侧）按得票比例涨出填充：首次出现 `scaleY 0→1` 500ms `--ease-rise`；之后新票到达时高度/宽度 400ms 过渡；我投的卡填充为 `primary-soft` | `forms.tsx`、`index.css` `.ticket-fill` |
| 首页格子错落入场 | 本次会话首页第一次加载：格子淡入、上移 14px、从 .98 放大，350ms，每格错开 40ms，第 11 格起同时；之后切筛选、翻页、返回不再播 | `pages/feed.tsx`（模块级 `played`） |
| 切换筛选/项目重排 | 格子 `layout` 350ms 平滑重排到新位置（dense 网格），离开的格子 150ms 淡出缩小，新格子 200ms 淡入；筛选分段与顶栏项目胶囊的选中块 `layoutId` 弹簧滑动 300ms | `pages/feed.tsx`、`shell.tsx` |
| 倒计时滚动 | 待办格倒计时每整分钟刷新；数字变化时旧值上移淡出、新值自下滚入，300ms | `pages/feed.tsx` `Roll`、`ui.tsx` `useNow` |
| 实时动态新事件 | 30 秒轮询（页面不可见时暂停，回来立即拉），新事件从顶部滑入（`y -14→0` 300ms），其余条目 `layout` 下移 | `pages/feed.tsx` `ActivityFeed` |
| 标题共享元素过渡 | 点格子标题进入详情：标题（`data-vt`）作为 `page-title` 300ms 移到题头 h1，其余内容交叉淡入；浏览器后退时反向（格子墙有模块级缓存，返回时立即渲染）；最多等目标 300ms；不支持 View Transitions 时直接切换 | `router.tsx`、`pages/feed.tsx`、`pages/view.tsx`、`index.css` |
| 进度环 | 参与人数变化时 `stroke-dashoffset` 500ms 过渡 | `pages/view.tsx` `Progress` |
| 迷你结果条 / 结果明细计数条 | 首次出现从 0 生长（`scaleX` 360ms），数字滚动到终值（450ms）；新提交到达时宽度过渡、整行闪一下主色底 | `pages/feed.tsx`、`pages/results.tsx`、`openui-lib/util.tsx` `CountUp` |
| 提交确认 | 提交按钮「✓ 已提交」勾描边画出 + 外圈柔光 480ms；结果可见时 900ms 后展开结果明细 | `forms.tsx`、`pages/view.tsx` |
| 命令栏 | 打开/关闭 200ms 缩放（95%↔100%）+ 淡入淡出 | `components/ui/command.tsx` |
| 路由切换 | 内容区 `.page-enter` 淡入 + 上移 4px，250ms | `main.tsx`、`index.css` |
| 按钮按下回弹 | 按下 75ms 缩到 `.97` 并下沉 1px；松开 320ms `--ease-spring` | `button.tsx`、`index.css` |
| 骨架屏微光 | `bg-muted` 上一道浅色高光扫过，1.4s 一轮 | `skeleton.tsx`、`index.css` |
| 图表首次绘制 | 550ms，只在首次进入视口时播一次 | `openui-lib/charts-impl.tsx` |

- 不做：鼠标跟随微光、噪点纹理、悬停抬起/放大、报告滚动逐块揭示、庆祝彩点。
- `prefers-reduced-motion: reduce`：所有 CSS 过渡与动画时长、延迟归零，去掉位移/缩放；票卡不翻面、填充直接到位；格子不错落入场；骨架屏微光、闪底色、成功柔光、勾描边不播；数字直接显示终值；不走 View Transitions；animate-ui 用 `AnimateUIProvider tempo=0.01`，motion 用 `MotionConfig reducedMotion="user"` + 默认过渡时长 0（`ui.tsx` `REDUCED`）。新增动效必须同时处理这两处。

## 6. 组件状态规范

| 状态 | 规范 |
|---|---|
| hover | 主按钮 `brightness(1.04)`；secondary/ghost 胶囊换 `accent` 底；格子不位移不放大（整格可点，标题是拉伸链接）；未选票卡底色换 `accent` |

| disabled | `opacity-50`、`pointer-events-none` |
| selected | 票卡：**3px 主色描边 + 卡片底**，字母变主色；Chips：主色描边 + 10% 主色底；顶栏项目胶囊：李子墨底 + 白字（`layoutId` 滑动底块）；筛选分段：白底胶囊滑动 |
| locked（已提交） | 每版每人限交一次。原题按提交数据回填：选中票卡加「✓ 你投的」标签（`data-on`），其余票卡 70% 不透明（`data-dim`），Chips 未选项 `opacity-45 saturate-50`，文本框只读；整组 `inert`；按钮「✓ 已提交（第 N 版）」；题头右侧锁定提示卡「你已投给 B. NATS / 第 N 版答案已锁定」；结果对我可见时票卡涨出比例。登录用户取 view 的 `my_response`，匿名访客与临时链接访问取 localStorage（`relay_resp_{page_id}_v{version}`）；HTML 页面由桥接脚本按 relay:init 的 `my_response` 回填锁定 |

| error | 校验失败：字段下方红字 + 提交按钮抖动；提交失败：按钮抖动并 `aria-invalid` 标红，按钮旁红字写明原因，`toast.err()` 带红色叹号并写明原因 |

### 工作台（首页、项目页）

- 头部：问候语（首页）/ 项目名（项目页）+ 副标题「本周新增 N 个页面，有 M 件事等你处理」+ 搜索框；下方类型分段：全部 / 投票 / 报告 / 流程与架构 / 表单 / 知识库，带计数。
- 卡片网格 `repeat(auto-fill,minmax(260px,1fr))`、间距 16px，按 `updated_at` 分组「今天 / 本周（含昨天）/ 更早」。卡片：类型图标方块 + 项目名 + 「某人 发布，时间」+ 状态徽标（等你投票 / 等你填写 珊瑚、你已投 / 你已填 薄荷、已截止 / 第 N 版 灰）、标题（拉伸链接，整卡可点）、内容预览（收集类前 6 张懒加载结果条，否则显示「n / N 人已投」与进度条；报告 `highlights` 三格或 `summary`；流程 / 架构通用缩略图；知识库 `summary` 按行显示为目录）、底部「✦ 模型」或发布者 + 票数与截止。
- 右栏 340px（≥ 1500 宽 372px）：实色「等我处理」面板（收集类、接受提交、未截止、我没交当前版本；按截止升序；倒计时圈按剩余时间占比走，剩余 < 2 天变珊瑚；按钮「去投票 / 去填写」；提交后卡片向右滑出）+「实时动态」（`GET /api/activity`，最多 12 条，30 秒轮询，接口 404 时不显示）。窄于 1280 时面板移到卡片上方（没有待办时隐藏）、动态移到卡片下方。
- 空状态：「接入 agent」引导（建令牌 + 复制 MCP 配置）。

### 页面详情

- 面包屑（组织 / 项目 / 标题）+ 搜索框；题头：48px 类型图标、28px 标题、元信息（类型、发布者、生成模型、第 N 版或版本下拉、更新时间、截止（珊瑚））。已提交时薄荷色锁定提示条「你在第 N 版投给了 B. NATS，答案已锁定…」。
- 主区 + 右栏 340px（≥ 1500 宽 392px），间距 28px；**窄于 1100px 时右栏移到内容下方**。
- 主区：OpenUI / HTML 内容 →「你的回答」（主色左边线）→「大家的理由」卡片网格（最多 6 条）→ 结果明细折叠区（`aria-label="结果"`，`?panel=results` 直达）→ 同项目的相关页面（只取列表缓存，最多 3 个）。
- 右栏：实时结果（「n / N 人已投」、薄荷进度条；已提交 / 截止 / 历史版本且结果可见时显示第一个选项字段的结果条，我的选择高亮，弹簧动效；提交者头像）、版本列表（点选写 `?version=`）、还没参与的人（`participation.pending`）、页面信息、按钮「分享链接 / 复制链接 / 管理」。「管理」打开对话框（页面设置与临时链接）。
- 票卡：单选 / 多选一律竖排选项行（68px 高：40px 字母方块、名称、说明；选中 2px 主色描边 + 主色浅底、字母方块实色；锁定后其余 50% 透明；有结果时从左侧按比例填充并显示票数），不撑破承托卡；选项标签「B. NATS」拆成字母 B + 名称 NATS，没有字母前缀时按序号补 A、B、C；radio / checkbox 本体视觉隐藏，承担键盘与读屏（`aria-label` 为完整标签）。

### OpenUI 内容

- KPI、图表卡、表格自身是 `surface`；已在卡片里的表格/表单/图表不再加表面（`InSurface` 上下文）。外壳题头 h1 已是页面标题，正文第一个 `large-heavy` 标题与之相同时隐藏。
- 多列规则：KPI / Snippet / Overview 卡 `auto-fit minmax(220px,1fr)`；纵向 Stack 中连续 ≥ 2 个图表卡自动并排（≥1280px 两列，≥1800px 三列）；横向 `Stack(…, "row", …, wrap=true)` 子项 `flex: 1 1 220px`；环形/饼图容器宽 ≥ 420px 时图例放右侧。
- 文本输入框最宽 `max-w-3xl`；正文段落 `.md p/li` 最宽 `80ch`。
- 自动多列与票卡只改渲染，不改提交数据格式（`{action, form, values, params}`，见 `docs/api.md`）。

## 9. 经典主题（Windows 98，可切换）

默认仍是方向 A。用户在「设置 › 外观」（或头像菜单、命令栏「切换到经典主题」）切到经典后，`<html data-skin="classic">`，选择只存本机 `localStorage`（键 `tk-skin`，读不到按默认），经典主题强制亮色（不加 `.dark`），动效全部关闭。

- token：`theme.css` 末尾 `[data-skin=classic]` 一组（灰窗面 `#c0c0c0`、藏青 `#000080`、16 色调色板、圆角 0、`--shadow-card` = 蚀刻分组框、`--shadow-pop` = 凸起窗口 bevel，另有 `--w-*` bevel 变量）。
- 样式：`web/src/classic.css`（由设计稿 win98.css 演化，bevel 用 inset box-shadow）。**每条规则都以 `[data-skin=classic]` 开头**，文件不进 cascade layer，所以能盖过 Tailwind 工具类而不影响默认主题。shadcn 组件按 `data-slot` 换皮（按钮另有 `data-variant` / `data-size`）；页面里需要的钩子用 `data-*` 属性（`data-panel`、`data-box`、`data-bar`、`data-check3`、`data-initial`），不改默认外观。
- 外壳：`web/src/classic.tsx`（资源管理器窗口、文件夹树、任务栏 + 开始菜单、右侧停靠小窗 `Dock`、属性对话框 `ClassicSheet`）；像素图标 `web/src/pixel-icons.tsx`（内联 SVG，不外链）。首页列表视图与停靠小窗在 `pages/feed.tsx`。
- 字体：系统栈 Tahoma / "MS Sans Serif"，中文 SimSun / 宋体回退，12px；不加载网络字体。
- 手机（≤ 760）：窗口全屏、树收进「开始」菜单、触控目标 ≥ 32px。
- 新增组件或页面时：默认样式照旧写；如经典下明显不协调，在 `classic.css` 里按 `data-slot` 或 `data-*` 钩子补规则，不要给默认主题加条件类。
